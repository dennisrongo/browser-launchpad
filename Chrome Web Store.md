Browser Launchpad transforms your new tab page into a powerful, personalized dashboard. Organize your digital life with customizable widgets, multiple pages, and beautiful themes.

WIDGETS
- Bookmarks — Save and organize your favorite links with folders, custom icons, and quick access
- Weather — Real-time weather for any city using OpenWeatherMap
- AI Chat — Chat with an AI assistant powered by OpenAI (GPT models), with Markdown-formatted replies
- Clock — Display time for any timezone worldwide, in four font styles (modern, classic, digital, elegant)
- Calendar — Month or week view; connect Google Calendar to see upcoming events, and click any date for that day's schedule
- Notes — Quick Markdown notes that sync across your browser
- Todos — Task lists with tags, priorities, due dates, plus sorting and filtering
- Pomodoro — Focus timer with customizable focus and break durations and session history
- Google Tasks — Two-way sync with your Google Tasks lists (create, complete, and edit tasks)
- Kanban Board — Organize work into custom columns and drag cards between them
- X Timeline — View your X (Twitter) "For You" or "Following" feed with auto-refresh and auto-scroll

FEATURES
- Multiple Pages — Create up to 10 separate dashboard pages for work, personal, projects, and drag to reorder them
- Customizable Grid — Choose 1-6 columns to fit your workflow
- Drag & Drop — Rearrange widgets within a page or move them between pages
- Beautiful Themes — 11 curated light and dark themes with elegant color palettes
- Google Drive Sync — Back up your bookmarks and settings to the cloud
- Import/Export — Full data backup and restore with JSON files
- Privacy First — Your data stays in your browser; API keys are never shared

GETTING STARTED
1. Install the extension
2. Open a new tab
3. Add widgets using the + button
4. Customize in Settings

OPTIONAL INTEGRATIONS
Some widgets require a free API key or account sign-in:
- Weather: OpenWeatherMap (free tier available)
- AI Chat: OpenAI
- Calendar: Google Calendar (OAuth sign-in)
- Google Tasks: Google account (OAuth sign-in)
- Cloud Sync: Google Drive (OAuth sign-in)
- X Timeline: uses your existing x.com session (sign in to X in the same browser)

Built with React, TypeScript, and Tailwind CSS. Open source and privacy-focused.
